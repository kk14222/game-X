# game-X

一个原生 Android 单机小游戏合集。

## 已包含游戏

- 猪了个猪：更多随机猪群冲刺解谜，点击朝向不同的小猪向八个方向冲出围栏，全部离场即可过关。
- 羊了个羊：多层叠牌三消，未被覆盖的牌可进入 7 个槽位，三张同款自动消除（槽位将满时会变红预警）。
- 跳一跳：按住蓄力、松开跳跃，落到下一个方块得分，中心落点额外加分。
- 合成大西瓜：顶部投放水果，相同水果合成更大水果，超过顶部警戒线结束。
- 合成 2048：手势滑动方向移动数字，合成 2048 后继续挑战高分（按数值上色，合并时显示得分增量）。
- 消消乐：8×8 糖果棋盘，点选或滑动交换相邻糖果形成三连消除并连锁，每关有目标分和步数限制。
- 坦克大战：13×13 网格，方向键 + 开火键控制玩家坦克，击毁全部敌军过关，老鹰基地被击中失败（前 3 关固定地图，之后随机生成）。

游戏进度、最高分和关卡会保存到安卓本地 `SharedPreferences`。
